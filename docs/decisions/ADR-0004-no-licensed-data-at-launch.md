# ADR-0004 · 首发不依赖商业地图与授权高程数据

- 状态：Accepted
- 日期：2026-09-10

## 背景
维州 1 m LiDAR / DSM 为 Licensed；Google Solar API 用途限定能源系统；Geoscape 免费额度口径不一【引】。单人谈许可是时间黑洞。R1 只需要现场采集。

## 决定
Spike 与 V1 不依赖任何需要谈判的数据。地址级粗估（V1.5）只用许可清楚的开放数据，并作为"看房前预估"与实测并列。墙面对齐用到的建筑轮廓引入前登记许可。

## 备选
- 先买 LiDAR 做地址级档案：已被 Sunscore 商品化，且许可条款可能禁止对公众展示派生结果。

## 后果
没有"零许可"捷径：自采数据也要授权；开放数据也有条款。
