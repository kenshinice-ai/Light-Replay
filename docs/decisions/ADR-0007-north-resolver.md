# ADR-0007 · 真北是多来源一致性问题；不确定性以时段表达

- 状态：Accepted
- 日期：2026-09-10
- 取代 / 被取代：后果中"冲突时只出 R0"的适用范围由 ADR-0009 细化

## 背景
磁罗盘室内不可靠；太阳校准只在晴天可用；VPS 只在户外有覆盖；墙面对齐依赖轮廓数据与用户指认。没有单一来源。用户关心几点到几点。

## 决定
NorthResolver 收集候选、按独立组融合、检测冲突、输出 Δ 与 σ_Δ；SunEngine 对 Δ 采样，把不确定性表达为"稳定直射 / 方向敏感 / 遮挡 / 资料不足"的时段。墙面对齐是室内阴天的首选候选，精度由 spike 测定，不预先承诺 1–2°。

## 备选
- 单一来源开关：脆弱。
- 强行平均冲突来源：把错误藏进平均值。

## 后果
结果页显示方向来源与 σ；冲突时只出 R0 并要求一次最小确认。
