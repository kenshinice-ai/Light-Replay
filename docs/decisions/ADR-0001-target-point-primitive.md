# ADR-0001 · 分析原语是 TargetPoint × 天空可见域

- 状态：Accepted
- 日期：2026-09-10

## 背景
庭院座位、阳台、客厅沙发位的问题形式相同：从这个点看，太阳何时在天空可见的部分。v4 提出"点的天空半球"，v5 指出窗边的可见域不能搬到沙发位（近处遮挡有视差），v6 加了目标点必须是镜头所在点。

## 决定
分析单位是 TargetPoint（位置 + 高度）及其四态可见域。窗框、墙、檐口、邻楼、树都只是这个点看出去的遮挡；R1 不需要窗的公制几何。换一个点就是另一次采集。

## 备选
- 以"房间"为单位：需要完整几何与外部遮挡距离，V1 做不到，且容易把点级结果误读成全房间。
- 以"窗"为单位：回答的是窗，不是人坐的地方。

## 后果
产品语言变成"你站在哪里，答案就是哪里"；R2 光斑需要额外几何，后置；多点比较成为自然功能。
