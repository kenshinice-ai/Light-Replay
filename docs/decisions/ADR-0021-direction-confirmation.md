# ADR-0021 · 方向确认：保存不设障；R1 要罗盘以外的证据；太阳圆面是待验证的第一条路径

- 状态：Accepted（2026-10-04，Lee 认可方案 v2 并要求结合 Codex 的 v2 复审开工）
- 日期：2026-10-04
- 影响：`00-blueprint.md` 第 21 行；`04-capture-protocol.md` §7；`05-north-resolver.md` §2a；`07-spike-plan.md` §5、§5a；`03-scene-record.md` §11
- 依据：`reviews/2026-10-04-light-replay-plan-review.md` R04；`reviews/2026-10-04-light-replay-plan-v2-review.md` V2-01、V2-02、V2-06

## 背景
真机上罗盘的 σ 是 10–20°【验 2026-10-03 四份记录】。一组且 σ > 6° 是阻断（ADR-0009、ADR-0018），所以只靠罗盘的扫描永远是 R0。要出时段，必须有罗盘以外的方向证据。v2 初稿把"对一下太阳"写成了自带可靠检查的路径；复审用一个反例否定了这一点：竖直反射面保持高度角不变（`d' = d − 2(d·n)n`，`n_y = 0` 时 `d'_y = d_y`），同高度的反光能通过高度角残差，而方位可以差几十度；融合器按传入的证据工作，分辨不出来。

## 决定
1. **保存永远可以。** 方向证据不足时，扫描保存为参考（R0），界面说明原因；不把任何确认做成保存的前置。
2. **R1 需要至少一个罗盘以外的有效方向候选**，并通过既有的融合与佐证规则（ADR-0009、ADR-0018）。不为此放宽 σ 或门槛。
3. **太阳圆面是第一条要做实验的路径，不是已成立的能力。** 候选有效性规则 `sundisk-0.1`（`05` §2a）是必要条件的集合：高度角残差、无近处表面、周围是天空、买家确认、追踪连续。**通过这些检查不证明目标是太阳**；它们只拒绝确定不是的候选。两端校验器拒绝"声称有效但证据不过"的记录，并保留一个通过了全部检查的镜面反例作为 fixture，提醒这条规则的边界。
4. **罗盘的预测位置只作搜索提示。** 在提示范围内选出的结果不再算作罗盘对它的独立佐证（ADR-0018 的佐证规则本来也不会让 σ 13° 的罗盘佐证任何东西）。
5. **第一个真实闭环只用原地能确认太阳的目标点。** 走到别处确认是单独的实验：确认段的帧标 `role: calibration`，不进入可见域，原扫描的漂移记录原样保留；追踪中断、重定位或不能证明连续时，不沿用旧 Δ，记录保持 R0。往返闭合差是能否把候选用到原网格的判据之一，不是只报告的数字。
6. **适用范围由实验决定。** 初始实验优先覆盖能获得可靠太阳圆面证据的场景；"晴天才有时段"在实验通过前只是实验范围，不写成产品承诺。窗光斑、墙面对齐各自列依赖后再排期。

## 后果
- `07` §5 登记候选线（测前）：方向误差、同高度假目标的误接收率、拒绝率；§5a 写挑战集与统计口径。报告同时给失败、拒绝、放弃与救场，不只给成功确认的分位数。
- 若挑战集表明单一太阳路径做不到可靠拒绝：先限定经验证的采集条件，或加独立确认；不靠缩小标称 σ。
- 确认耗时计入 OneTake 时长指标。

## 备选
- 放宽"一组且 σ ≤ 6°"到能容纳罗盘：色带大半是敏感段，等于在猜；且与 ADR-0018 刚收紧的方向相反。放弃。
- 把确认做成保存前的必经步骤：阴天与看不见太阳的房间无法保存。放弃。
