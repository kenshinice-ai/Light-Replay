# 13 · 名词表

文档与代码只用这里的名字。按主题排。

## 产品

| 名词 | 定义 |
|---|---|
| **TargetPoint** | 用户关心的那个点：镜头所在位置 + 确认的高度（如沙发眼高 1.15 m）。结果只对这个点成立 |
| **OneTake** | 一次采集会话：锚定并拍 Hero、原位扫天、方向确认，一气呵成 |
| **Hero frame** | OneTake 开始时的高分辨率主照片，结果页的背景 |
| **Viewpoint Lock** | 扫描期间镜头中心应留在锚点附近；偏离量叫漂移，按深度修正或降权 |
| **SceneRecord** | 一次采集的全部证据：帧、姿态、掩膜、方向候选、可见域、分析结果、质量与来源 |
| **R0 / R1 / R2 / R3** | 证据等级：参考 / 点级 / 接收面 / 空间。见蓝图第 5 节 |
| **潜力投影** | R2 里未计外部遮挡视差的窗光斑形状；只回答"在哪"，不回答"多久" |
| **Light Passport** | 带来源标签的挂牌日照页（V1.5） |
| **参考模式** | 只画太阳弧、不出小时数的模式（R0） |

## 几何与光

| 名词 | 定义 |
|---|---|
| **方位角 az** | 水平方向，真北 0°，顺时针到 360° |
| **高度角 alt** | 与水平面的夹角，地平线 0°，天顶 90° |
| **太阳向量** | 某时刻太阳的 (az, alt)，由 SPA 算出 |
| **可见域 / 天空可见域** | 从 TargetPoint 看，每个 (az, alt) 单元是天空、遮挡、未知还是玻璃不确定 |
| **四态** | 天空 / 遮挡 / 未知 / 玻璃不确定 |
| **太阳走廊** | 查询时段内太阳会经过的 (az, alt) 集合，外扩 3°；覆盖率只按它算 |
| **视差** | 换一个观察点，近处遮挡的方向会变；远处几乎不变。原因是距离 |
| **深度重投影** | 用 LiDAR 深度把近场遮挡点换算到 TargetPoint 的视角 |
| **D_near** | 判定近场的深度阈值（候选 4 m） |
| **直射** | 太阳向量落在可见域的天空单元 |
| **稳定直射 / 方向敏感 / 遮挡 / 资料不足** | 时段四色：对方向采样的直射比例 ≥95% / 之间 / ≤5% / 太阳穿过未知 |
| **归因** | 某遮挡时段对应的方向范围与命名（如"西侧建筑，实测"） |

## 方向

| 名词 | 定义 |
|---|---|
| **真北** | 地理北；磁北经磁偏角修正后得到 |
| **yaw / Δ** | AR 世界 −Z 轴的真方位角（俯视顺时针）；`az_true = az_ar + Δ`。北向修正只改它 |
| **σ_Δ** | Δ 的不确定性（度） |
| **NorthResolver** | 收集方向候选、按独立组融合、检测冲突、输出 Δ 与 σ_Δ 的模块 |
| **独立组** | 物理上独立的方向来源家族：magnetic / map / solar / vps / truth |
| **墙面对齐** | 用 AR 检测的墙面法线对上建筑轮廓的边方向，得到 Δ |
| **窗光斑校准** | 用地上光斑的边与窗边的对应关系解出太阳方向，反推 Δ |
| **日晷真值** | 竖直杆的影子给出真太阳方位；只用于 spike 基准 |
| **VPS** | 视觉定位服务，户外有覆盖时给高精度姿态。Spike 用 ARKit 地理追踪；ARCore Geospatial 为候选，引入前登记许可 |

## 设备

| 名词 | 定义 |
|---|---|
| **ARKit 世界追踪** | 视觉惯性里程计；给相对姿态，短程厘米级；没有真北 |
| **LiDAR / sceneDepth** | iPhone Pro 的深度传感；约 256×192，约 5 m 内 |
| **RoomPlan** | Apple 的房间参数化扫描；能输出墙、窗、门对象 |
| **内参 K** | 相机焦距与主点，把像素变成射线 |
| **追踪状态** | normal / limited / not available；limited 时帧降权 |

## 验证

| 名词 | 定义 |
|---|---|
| **真值** | 独立于 App 的观测：延时里白卡上的进出时刻、日晷方向 |
| **holdout** | 不参与调参的场景集；只用于最终评估 |
| **false-valid** | 质量不够却输出确定小时数；一票否决 |
| **accepted 场景** | 通过四个质量灯的场景；误差统计只算它们 |
| **候选通过线** | 预注册的指标阈值；修订走 ADR |

## 标注

【验】本轮核实过来源。【引】引自前稿、未复核。【估】推断或假设。
