# 06 · SunEngine：太阳几何、采样、时段分级

版本 0.1 · 2026-09-10

## 1. 太阳位置

- 算法：NOAA / SPA 级精度实现（Swift 自写，约 200 行），输出方位角（真北 0°，顺时针）与高度角，含大气折射修正。
- 输入：纬度、经度、海拔、时刻（UTC）。时区与夏令时由 `timezone`（IANA）转换；用户出国回放时仍用场景所在地时区。
- 验证：与 pvlib `solarposition` 对照，24 小时 × 12 个月 × 南北半球各 3 个地点，误差 < 0.05°。

## 2. 参考公式（平地、忽略折射，只用于校验与走廊粗估）

- 正午高度：`90° − |φ − δ|`，赤纬 δ 在 ±23.44°。
- 日出方位：`acos(sin δ / cos φ)`；日落 `360° −` 该角。
- 墨尔本 φ = −37.81°：冬至正午 28.8°，夏至 75.6°；冬季日出约 60°，夏季约 120°。
- 悉尼 φ = −33.87°：32.7° / 79.5°。

## 3. 采样

- 全年：5 分钟步长 × 365 天 = 105,120 个时刻（闰年 105,408）。
- 边界细化：某时段状态变化处用 1 分钟步长二分，得到进出遮挡时刻。
- 只在太阳高度 > 0 时评估；低于地平线不计入覆盖率分母。

## 4. 直射判定

对时刻 t：太阳 (az_true, alt) → 转 AR 方位 `az_ar = az_true − Δ` → 查可见域单元状态：天空 = 直射；遮挡 = 遮挡；未知或玻璃不确定 = 资料不足。太阳圆面半径 0.27°：取以太阳为中心 ±1 单元的多数态，边界记敏感。

## 5. 太阳走廊

给定查询（日期范围、时段）：枚举采样时刻的 (az_true, alt)，转成 AR 方位（用当前 Δ 估计），外扩 3°，得到走廊单元集合。覆盖率 = 走廊内非未知单元 / 走廊单元。

## 6. 时段分级

1. 采样 `Δ_k ~ N(Δ, σ_Δ)`，k = 1..K（候选 64）；边界抖动 ±1°。
2. 每个采样得到一条全年状态时间线。
3. 逐时刻统计直射比例 p：p ≥ 0.95 → 稳定直射；p ≤ 0.05 → 稳定遮挡；否则 → 方向敏感；若任一采样落在未知单元 → 资料不足。
4. 合并成时段；输出每日时段、热力图、每月与冬至/夏至的稳定直射小时与"上界"（未知全部按天空计）。

## 7. 归因

对每个遮挡时段，取太阳经过的遮挡单元的方位与高度范围，按方向命名（西侧、北偏东等），标注来源（实测）。

## 8. 输出

见 `03-scene-record.md` 第 7 节。数字给区间与整分钟；不给小数点。

## 9. 测试

- 已知地点的日出日落与 NOAA 表对照。
- 合成可见域（全天空、半边遮挡、水平地平线 10°）的时段与解析解对照。
- 夏令时切换日、跨年、闰日。
- 未知单元存在时，任何输出不得写成稳定直射。
