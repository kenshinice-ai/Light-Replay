# 01 · 产品规范：用户流程、证据等级、结果页

版本 0.1 · 2026-09-10 · 对应蓝图第 3、5 节

## 1. 用户与任务

| 用户 | 任务 | 现场约束 | 首发 |
|---|---|---|---|
| 自住买家、租客 | 在 open home 弄清"这个座位冬天几点有太阳" | 15–30 分钟看房；多为阴天；不能开窗、不能移家具；中介在场 | V1 |
| 已有屋主 | 植物位、书桌位、晾晒点 | 时间充裕；可多点 | V1 顺带 |
| Paradise Production 采集员 | 挂牌拍摄时顺手采 2–3 个点 + 延时真值 | 每套房 ≤ 3 分钟额外时间 | V1.5 |

以任务招募，不以族裔或"喜欢科技"招募。

## 2. OneTake 流程

```
选问题 → 锚定并拍 Hero → 原位扫天 → 质量门槛 → 结果 → 比较 / 分享 / 复看
```

| 步 | 用户看到 | 系统做什么 | 时间预算 |
|---|---|---|---|
| 选问题 | "冬季早餐" / "全年" / "下午西晒" / 自定义时段 | 生成太阳走廊；决定要覆盖的方位与高度范围 | 5 s |
| 锚定并拍 | 把手机放到目标高度（坐姿眼高约 1.15 m，或对准植物叶面）；按下开始 | 记录镜头锚点、Hero frame、时刻、位置与精度、姿态、曝光 | 5 s |
| 原位扫天 | 覆盖率环；缺口高亮；漂移提示"回到圆圈" | 逐帧姿态与掩膜；深度重投影；走廊覆盖率；方向候选并行记录 | 15–30 s |
| 质量门槛 | 四个灯：水平、覆盖、方向、分割 | 任一不达标只出 R0；达标出 R1 | 即时 |
| 结果 | 照片 + Target Pin + 时间滑杆 + 时段条 | SunEngine 全年计算；时段分级 | < 1 s |

覆盖率不是越高越好：只补会改变当前问题答案的那几度天空。

## 3. 结果页（R1）

- **照片区**：Hero frame；Target Pin；当前时刻的太阳方向指示（在画面内画方向，不画假光斑）。
- **时间滑杆**：当天 24 小时；拖动时太阳方向随动，时段条上的游标同步。
- **日期**：冬至、夏至、春秋分快捷；任意日期。
- **时段条**：四色。稳定直射 / 方向敏感的边界 / 被遮挡 / 资料不足（太阳穿过未知天空）。
- **全年热力图**：日 × 小时，同样四态。
- **结果卡**：
  - "6 月 21 日约 10:40–14:10 直射（其中 10:40–11:00 对方向敏感）"
  - 遮挡归因："14:10 后：西侧建筑（实测）"
  - 北向来源与 σ；采集时刻；未计入项（窗帘、玻璃透光率、活动遮阳、云）。
- **证据卡**（每个数字可展开）：来源、算法版本、覆盖率、未知比例、质量灯状态。
- **复看建议**："若想确认 11:00 前的边界，晴天 10:30–11:15 回到同一点看一眼。"

措辞：给区间，不给小数点；标注采集日期；不写"以实测为准"，写"实测通过质量检查"；分歧写"待复核"。

## 4. R2 潜力光斑（V2，LiDAR 机型）

- 在 R1 之上，用 RoomPlan 的窗四角与地面平面，沿太阳向量投影窗多边形。
- 显示为虚线半透明，标签"潜力投影：未计窗外遮挡的视差"。
- 时段仍来自 R1 的点级实测；光斑只回答"形状在哪"。

## 5. 比较页

两个点并排：同一日期的时段条、冬至直射小时、未知比例、采集条件。缺数据的维度显示"未采"，不用中间值填。

## 6. 分享页

- 默认包含：时段条、热力图、结果卡、证据卡摘要、采集日期、目标点标签。
- 默认不含：原片、精确门牌、EXIF、位置精度以外的坐标。
- 链接可撤销；更正后旧链接显示更正状态。

## 7. 参考模式（R0）

导入照片或只输入地址：画太阳弧与方向；允许手工设北向；**不输出小时数**。用于"先看看"，也是无权限时的兜底。

## 8. 降级矩阵

| 条件 | 行为 |
|---|---|
| 系统低于 iOS 27 | 不支持（ADR-0011） |
| 无 LiDAR | R1 可用；漂移按阈值处理并标注；R2 不可用 |
| 非 Apple Intelligence 机型，或未开启、资源未下载、语言不支持 | 教练句与文案用模板；帧级反射标记改用启发式；结果不变 |
| PCC 不可用或额度用尽 | 报告文本改端侧或模板 |
| 分割模型资源未下载 | 手工标注天空区域（涂抹）；标注"手工分割" |
| 无精确定位 | 用户在地图点位置；位置来源标"手工" |
| 方向来源全部无效 | 只出 R0 |
| 追踪丢失、运动模糊 | 该段帧不并入；覆盖率相应下降 |

## 9. 不出结果的情况

以下任一出现时，只显示 R0 与原因，不显示小时数：走廊覆盖率低于门槛；方向来源冲突且无法解决；玻璃反射污染且未识别为未知；漂移超出可修正范围。**错误却确定的输出是阻断性缺陷。**
