## 2. 传统太阳工具

Sun Seeker、Sun Surveyor、PhotoPills、Sunlitt、SunOnTrack、Sun AR：AR 太阳轨迹、地图、部分自画物体阴影与场景保存。它们不做现场可见域实测，不做质量门槛，不出证据链。**不要写成"都只画太阳弧线"**：Sunlitt 与 SunOnTrack 有自画物体阴影【引】。

## 3. 太阳能行业

Solmetric SunEye、Solar Pathfinder、Aurora、OpenSolar：地平线采集方法的行业先例。方法成立，场景不同。Google Solar API 的用途条款限定能源系统【引】。

## 4. 我们要实测证明的增量

1. 同一扇窗，能否更快得到有效记录（≤ 40 秒）。
2. 能否发现对方或自己未处理的外部遮挡。
3. 能否说清"这个数字针对哪个点"。
4. 用户是否因此改变复看、座位或购买比较。

## 5. 观察名单

- Shadowmap 是否与 REA / Domain 合作。
- Direct Sun Tracker 是否加入现场天空扫描。
- Apple 是否把"按时间重打光"做进系统相册。
- Sunnook 是否公开发布并加入外部遮挡。
