## 补记（10-01）：R08

复审的六个探针（`2026-09-30-reaudit-probes.py`）现在在 Swift 与 Python 两边都被拒绝，理由逐字相同：

| 探针 | 结果 | 拒绝在哪 |
|---|---|---|
| 缺 lens | REJECT | `$.quality.gates: missing lens`（上一轮已修） |
| 帧时间超出会话 | REJECT | `$.capture_session.frames[0].t`（上一轮已修） |
| 只有一组方向，σ = 12° | REJECT | `$.quality.gates.north`：写的是 warn，证据给出 blocked |
| 覆盖 1%，灯写 pass | REJECT | `$.quality.gates.coverage`：证据给出 blocked |
| 玻璃占走廊 90%，灯写 pass | REJECT | `$.quality.gates.segmentation`：证据给出 blocked |
| 目标锚点与锁定锚点不同 | REJECT | `$.quality.level`：两个锚点相距 7.000 m，不是同一视点 |

做法：

- **NorthResolver 融合**（`ios/Packages/NorthResolver`，Python 对照 `engine/lightreplay/north.py`）：组内圆周中位数、两两一致性、最大一致组合、加权圆周均值、方向灯，按 `05` 第 3 节与 ADR-0009。`02` 第 6 节列的九种合成情形都有用例；`03` 第 4 节的例子算出 359.78° / 1.77°。
- **QualityEvaluator**（SceneRecord 包内，Python 对照 `engine/lightreplay/quality.py`）：走廊覆盖、方向、分割三盏灯按证据重算，校验器最后调用它。写入值与证据不同就拒绝，说高了说低了都一样，R0 记录也查。高于 R0 的记录另查物理自洽（两个锚点同一点；并入可见域的帧追踪正常且在 0.40 m 漂移上限内）。`north.resolved` 若存在，必须是候选融合出的结果。放在 SceneRecord 包里是有意的：能读进来的记录都已过这一关，不依赖调用方再查。
- **heading 原始样本**：采集里每一条能与姿态对上的罗盘读数都写进 `raw.samples`（俯仰超过 50° 的保留但不参与合并）；候选取圆周中位数，σ 取"读数精度 / 扫动过程中的分散 / 8° 先验"的最大值。罗盘在转动中漂移，现在会体现在 σ 上。
- Builder 的方向灯改为写 NorthResolver 算出的结果；需要确认的方向不写 `resolved`。Builder 仍然只出 R0。

测试：Swift NorthResolver 9、SceneRecord 33（原 28 + 5）、CaptureCore 19（原 13 + 6，含一次 60 秒 / 3600 帧 / 2000 条读数的记录在 0.25 秒内建好）；Python 67（原 36 + 方向 23 + 质量 8）。期望值按文档手写（方向 19 个具名情形，有一个测试保证每个具名情形都有人写了期望；质量 29 个用例），另有 200 个随机方向输入只用于两种实现对齐。旋转不变性与候选顺序无关性在 Python 侧有性质测试。

没有做到、要说明的：

- **水平与追踪、镜头两盏灯没有重算。** schema 0.1.0 不带这两个检测器的证据（地平线一致性、脏污检测结果），评估器只能按写入值，只查了能查的那部分。要补就得先给 schema 加字段。
- **分割灯的"反射未识别"没有判。** 同样是没有可重算的证据；现在只按玻璃不确定占比判。
- **一个确认过的盲区。** σ 很宽的组无法与任何组冲突：罗盘 σ 12° 能藏住 17° 的错误（ADR-0009 已记）；极端情况下一组读数互相矛盾、σ 到 90°，仍被算作"第二个独立组一致"而亮绿灯。按已接受的 ADR-0009 实现，没有擅自加规则；两种情形各有一个命名测试固定现状，并写进 `05` 第 7 节作为 spike 要回答的问题。建议在解锁 R1 之前定下来：作为佐证的第二组是否要有 σ 上限。**10-03 已定（ADR-0018，Lee 授权）**：不看单组 σ，看一对合起来能分辨多大的错——冲突门槛 ≤ 15° 的一对才算佐证；没有佐证对的组合按一组处理。两种盲区都关掉，`northresolver-0.2`。
- **solar 候选自身的残差检查（ADR-0009 规则 6）没有实现。** 它属于产生候选的一方；融合只认候选上的 `valid` 标记。现在没有 solar 来源，所以还没有地方需要它。
- 所有门槛仍是候选；这一轮没有任何现场数据。
